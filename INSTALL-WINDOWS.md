# Установка Hermes на Windows 10/11

Пошагово, без командной строки — только мышь и один раз PowerShell.
Время: 20–30 минут, из них 10 — скачивание.

---

## Что нужно от компьютера

- Windows 10 **64-бит, версия 22H2** (сборка 19045) или Windows 11. Home подойдёт.
- **8 ГБ RAM минимум**, комфортно 16 ГБ. Меньше 8 — не ставь, будет тормозить.
- **12 ГБ свободного места** на диске C: (образ ~11 ГБ + запас).
- В BIOS включена виртуализация (VT-x / AMD-V). Как правило, включена по умолчанию.

Проверить версию Windows: `Win + R` → `winver` → Enter.

---

## Шаг 1. Включить WSL2

WSL2 — Linux-подсистема, на ней работает Docker.

1. Нажми `Win`, введи **PowerShell**.
2. Правый клик по «Windows PowerShell» → **Запуск от имени администратора**.
3. Вставь строку и нажми Enter:

```powershell
wsl --install
```

4. Дождись окончания и **перезагрузи компьютер**.
   Если написано «WSL уже установлен» — просто перезагрузи и иди дальше.

После перезагрузки может открыться окно Ubuntu с просьбой придумать логин —
это необязательно, окно можно закрыть. Hermes работает без него.

---

## Шаг 2. Установить Docker Desktop

1. Открой https://www.docker.com/products/docker-desktop/
2. Нажми **Download for Windows – AMD64** (для обычного ПК).
3. Запусти скачанный `Docker Desktop Installer.exe`.
4. В установщике оставь галочку **Use WSL 2 instead of Hyper-V**, нажми **Ok**.
5. После установки — **Close and restart**. Компьютер перезагрузится.
6. После перезагрузки запусти **Docker Desktop** (иконка кита на рабочем столе).
7. Прими лицензию, предложение войти в аккаунт пропусти (**Skip** / **Continue without signing in**) —
   аккаунт не нужен.
8. Дождись в левом нижнем углу зелёной надписи **Engine running**.

---

## Шаг 3. Проверить режим Linux

Docker Desktop умеет два режима; нужен Linux.

1. Правый клик по **иконке кита в трее** (рядом с часами; если не видно — нажми `^`).
2. Если в меню есть пункт **Switch to Linux containers** — нажми его.
   Если пункта нет — уже в нужном режиме.
3. Проверка: открой PowerShell (обычный, без админа) и введи:

```powershell
docker info --format "{{.OSType}}"
```

Должно вывести `linux`. Если `windows` — вернись к пункту 1.

---

## Шаг 4. Запустить Hermes

Вариант А — в один клик:

1. Скачай `start.bat` из репозитория: https://github.com/igsergor/hermes-preset
   (зелёная кнопка **Code** → **Download ZIP**, распакуй, нужен файл `start.bat`).
2. Двойной клик по `start.bat`.

Вариант Б — вручную в PowerShell:

```powershell
docker run -d --name hermes -p 127.0.0.1:9119:9119 -v hermes-data:/opt/data ghcr.io/igsergor/hermes-preset:latest gateway run
```

Что происходит: скачивается образ 11 ГБ (первый раз 5–15 минут, зависит от интернета),
затем контейнер стартует. Второй запуск — мгновенный.

Открой в браузере: **http://localhost:9119**

Первый старт — 1–2 минуты, страница может не открываться сразу. Обнови её.

---

## Шаг 5. Вставить ключ модели

Без ключа агент не отвечает. Ключ — от любого провайдера; проще всего OpenRouter
(один ключ — сотни моделей) или DeepSeek (дешевле всех).

**Где взять ключ**
- OpenRouter: https://openrouter.ai/keys → **Create Key** → скопировать (`sk-or-v1-...`).
  Пополнить баланс: https://openrouter.ai/credits (хватит $5 на недели работы).
- DeepSeek: https://platform.deepseek.com/api_keys → **Create new API key** (`sk-...`).
  Нужен минимальный депозит.

**Куда вставить**
1. В дашборде слева нажми **KEYS**.
2. Прокрути до **LLM PROVIDERS**.
3. Найди строку своего провайдера (**OpenRouter** или **DeepSeek**), кликни по ней —
   раскроется.
4. У строки с ключом нажми **Set**.
5. В поле **Enter value...** вставь ключ → **Save**.
6. Рядом появится метка, что ключ сохранён.

Ключ пишется в файл внутри контейнера и подхватывается сразу, перезапуск не нужен.

---

## Шаг 6. Выбрать модель

1. В меню слева открой **MODELS**.
2. У строки **MAIN MODEL** нажми **CHANGE**.
3. Слева выбери провайдера (OpenRouter / DeepSeek).
4. Справа появится список моделей. Для старта:
   - OpenRouter → `deepseek/deepseek-chat` или `anthropic/claude-sonnet-4.5`
   - DeepSeek → `deepseek-chat`
5. Нажми **Switch**. Готово.

---

## Шаг 7. Проверить, что всё работает

1. Слева **CHAT** → напиши «привет, кто ты?» → должен ответить.
2. Спроси: «что у тебя в памяти?» — агент читает волт `/opt/data/vault`.
3. Слева **CRON** — там три задачи (ночной разбор, переиндексация памяти,
   недельный обзор). Они начнут работать сами по расписанию.

Необязательно: **CHANNELS** → Telegram, если хочешь общаться с агентом из мессенджера.
Понадобится токен бота от @BotFather.

## Обновление

Новая версия выходит первого числа каждого месяца.

```powershell
docker pull ghcr.io/igsergor/hermes-preset:latest
docker rm -f hermes
docker run -d --name hermes -p 127.0.0.1:9119:9119 -v hermes-data:/opt/data ghcr.io/igsergor/hermes-preset:latest gateway run
```

Память, скиллы и настройки лежат в томе `hermes-data` — они не удаляются.
Или просто запусти `start.bat` ещё раз после `docker rm -f hermes`.

---

## Бэкап и удаление

Бэкап (архив всей памяти и настроек в текущую папку):

```powershell
docker run --rm -v hermes-data:/data -v ${PWD}:/out alpine tar czf /out/hermes-backup.tar.gz -C /data .
```

Полное удаление (включая память — необратимо):

```powershell
docker rm -f hermes
docker volume rm hermes-data
```

## Если что-то не так

**`docker: command not found` / «не является внутренней командой»**
Docker Desktop не запущен. Запусти его, дождись «Engine running», открой PowerShell заново.

**`docker info` показывает `windows` вместо `linux`**
Правый клик по киту в трее → **Switch to Linux containers**.

**Порт 9119 уже занят**
Значит Hermes уже запущен: открой http://localhost:9119.
Или занят другой программой — тогда запусти на другом порту, заменив `9119:9119` на `9220:9119`.

**Страница не открывается после запуска**
Подожди 2 минуты и обнови. Проверь, что контейнер жив:
`docker ps` → в списке должен быть `hermes` со статусом `Up`.

**`wsl --install` выдаёт ошибку**
Включи компоненты вручную: `Win + R` → `optionalfeatures` → отметь
«Подсистема Windows для Linux» и «Платформа виртуальной машины» → перезагрузка.

**Агент отвечает «No LLM provider configured»**
Ключ не сохранён или не выбрана модель. Вернись к шагам 5 и 6.

**Мало памяти / всё тормозит**
В Docker Desktop: шестерёнка → **Resources** → поставь лимит 4–6 ГБ и 2 CPU.

## Что внутри (чтобы понимать, чем пользуешься)

- 54 скилла: документы и OCR, поиск и research, GitHub, работа с видео, Obsidian.
- Память в Obsidian-волте: агент помнит факты между разговорами.
- Локальные эмбеддинги `bge-m3` внутри образа — поиск по памяти работает без интернета.
- Три крона: ночной разбор диалогов, переиндексация памяти, недельный обзор.

Ключи и личные данные в образ не зашиты — только твои, в твоём томе.
