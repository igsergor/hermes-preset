# PARA Methodology Quick Reference

> **PARA** = Projects, Areas, Resources, Archives — система организации информации Тиаго Форте (Building a Second Brain)

---

## 📂 Структура папок

```
obsidian-vault/
├── Projects/     # 🎯 Активные проекты с дедлайнами
├── Areas/        # 🏢 Области ответственности (нет дедлайна)
├── Resources/    # 📚 Ресурсы / Справочники (интересует)
├── Archives/     # 📦 Завершенное / Хранилище
├── Inbox/        # 📥 Быстрый захват (обрабатывать еженедельно)
├── Templates/    # 📋 Шаблоны заметок
├── Daily/        # 📅 Ежедневные заметки
└── .obsidian/    # ⚙️ Конфиг Obsidian
```

---

## 🎯 Projects (Проекты)

**Критерий**: Есть конкретный результат + дедлайн

```
Projects/
├── Hermes Agent — Настройка и расширение.md
├── Ремонт ванной.md
├── Выпуск Telegram-бота v2.md
```

- Каждый проект = одна заметка
- Внутри: задачи, ресурсы, критерии.done
- При завершении → переместить в Archives

---

## 🏢 Areas (Области)

**Критерий**: Стандарт качества, который нужно поддерживать постоянно

```
Areas/
├── Home & Family.md
├── Development & Tech.md
├── Health & Fitness.md
├── Finances.md
```

- Нет финишной линии
- Содержат под-области и регулярные действия
- Связаны с проектами (проект служит области)

---

## 📚 Resources (Ресурсы)

**Критерий**: Тема, которая интересует, может пригодиться

```
Resources/
├── CLI Шпаргалки.md
├── Docker Команды.md
├── Полезные репозитории.md
├── Книги и Курсы.md
├── Полезные контакты.md
```

- Чисто справочно
- Теги для навигации: #linux #docker #python
- Связывать с проектами: `[[Проект]]` использует `[[Ресурс]]`

---

## 📦 Archives (Архив)

**Критерий**: Завершенные проекты, неактивные области, старые ресурсы

```
Archives/
├── Projects/
│   └── 2025-Website-Redesign.md
├── Areas/
│   └── Old-Job-Responsibilities.md
└── Resources/
    └── Deprecated-API-Docs.md
```

- Не удалять — могут пригодиться для референса
- Папка = год или категория
- Поиск работает через весь vault

---

## 📥 Inbox (Входящие)

**Правило**: Всё новое попадает сюда сначала

- Быстрый захват из Telegram, браузера, идей
- Обрабатывать **еженедельно** (Weekly Review)
- Действие: Project / Area / Resource / Archive / Delete

---

## 🔄 Weekly Review (Еженедельный обзор)

1. **Inbox** → разобрать всё (5-10 мин)
2. **Projects** → обновить статус, перенести завершенные в Archives
3. **Areas** → проверить регулярные действия
4. **Calendar** → планировать следующую неделю
5. **Daily Notes** → просмотреть за неделю, вынести важное

## 🏷 Теги (рекомендации)

| Префикс | Назначение | Примеры |
|---------|------------|---------|
| `#project/` | Проекты | `#project/hermes-setup` |

## ⌨️ CLI Команды (через obsidian-vault skill)

```bash
obsidian daily              # Дневник сегодня
obsidian new -t Project "Название"  # Создать проект
obsidian search "запрос"    # Поиск
obsidian random -s          # Случайная заметка
obsidian stats              # Статистика
```

## 💡 Принципы

1. **Действие превыше организации** — не идеально структурируй, а работай
2. **Организуй по действию** — где ты это *используешь*, а не где *нашел*
3. **Еженедельный обзор** — единственный способ держать систему в актуальном состоянии
4. **Архив — не мусорка** — это база знаний для будущих проектов
5. **Ссылки > Папки** — граф связей важнее иерархии
