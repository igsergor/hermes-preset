# Hermes Agent — русский пресет

Готовый агент в одном контейнере: скиллы, память в Obsidian-волте, локальные
эмбеддинги. Всё, что нужно от тебя — поставить Docker, запустить контейнер и
вставить ключ любого провайдера в открывшемся дашборде.

## Что нужно

Пошаговая установка для Windows 10/11 — в файле [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).

- Docker Desktop (Windows, macOS) или Docker Engine (Linux)
- 8 ГБ RAM минимум, лучше 16
- ~10 ГБ свободного места на диске
- Интернет для первого `docker pull`

На Windows Docker Desktop сам поднимает WSL2 — отдельно ставить ничего не надо.
Только после установки переключи его в режим Linux-контейнеров (по умолчанию он
может стоять в режиме Windows): правый клик по иконке кита в трее →
**Switch to Linux containers**. Признак, что всё верно, — `docker info` показывает
`OSType: linux`.

## Запуск

```bash
docker run -d --name hermes \
  -p 127.0.0.1:9119:9119 \
  -v hermes-data:/opt/data \
  ghcr.io/igsergor/hermes-preset:latest gateway run
```

Или просто запусти `start.bat` (Windows), `start.command` (macOS), `start.sh` (Linux) —
они делают то же самое и открывают браузер.

Дальше открой **http://localhost:9119** → настройки → провайдер и ключ.
Модель подхватится без перезапуска, кроны оживут на следующем тике.

## Что уже работает без ключа

- **Память**: волт в `/opt/data/vault`, факты по одному файлу, поиск по ключевым словам.
- **Эмбеддинги**: Ollama + `bge-m3` (1024 измерения) уже внутри образа, CPU, офлайн.
- **Скиллы**: 54 штуки — документы, OCR, research, GitHub, делегирование агентам, видео, Obsidian.
- **Кроны**: ночной разбор сессий, переиндексация волта, недельный обзор. Без модели
  они не работают и пишут в историю `ProviderNotConfiguredError` — в чат ничего не
  приходит (доставка `local`), после подключения ключа следующий запуск проходит.

## Версии

Образ собирается ежемесячно (1-е число), теги — `latest` и дата сборки:

```bash
docker pull ghcr.io/igsergor/hermes-preset:2026.10.30   # конкретная сборка
```

Архитектуры: `linux/amd64` и `linux/arm64` (Intel/AMD и Apple Silicon, ARM-серверы).
Пакет публичный — `docker login` не нужен.

## Telegram (по желанию)

Попроси агента в дашборде подключить Telegram — он попросит токен бота от @BotFather.
Бот получает полный доступ к контейнеру, поэтому allowlist обязателен: первый
написавший проходит pairing, остальные — нет.

## Обновление

```bash
docker pull ghcr.io/igsergor/hermes-preset:latest
docker rm -f hermes
# снова docker run (данные в томе hermes-data не трогаются)
```

## Бэкап и сброс

```bash
# бэкап (архив всего профиля)
docker run --rm -v hermes-data:/data -v "$PWD":/out alpine \
  tar czf /out/hermes-backup.tar.gz -C /data .

# полный сброс — удаляет ВСЁ, включая память
docker rm -f hermes && docker volume rm hermes-data
```

## Чего здесь нет

- Electron-десктопа и GUI-автоматизации — только веб-дашборд и чат в нём.
- GPU и локальных LLM: Ollama используется только для эмбеддингов.
- Системных скиллов хоста (systemd, WireGuard, роутеры) — они не имеют смысла в контейнере.

## Важно про безопасность

Дашборд слушает только `127.0.0.1` на твоей машине. Наружу не выставляй: у агента
полный доступ к контейнеру и файлам внутри тома. Подтверждения опасных действий
включены по умолчанию.

Время внутри контейнера — UTC. Если ставишь свои кроны, учитывай сдвиг.

## Проверено

Сборка от 2026.10.30 проверена на чистой машине: контейнер поднимается одной
командой, дашборд отвечает, 54 скилла на месте, `bge-m3` отдаёт эмбеддинг,
индекс волта строится и находит запись, ключ из дашборда даёт первый ответ без
перезапуска, `docker restart` ничего не теряет.
